**Bounded Schrödinger potentials for robust learning in generative models** 

Elvezio Ronchetti and I, we propose a new class of M-estimators  (based on a robust Sinkhorn divergence) for robust learning in generative models and show that their influence function is bounded. 
This guarantees B-robustness. The standard influence function representation is inapplicable because the estimating equation depends on the entire empirical measure and lacks 
the usual observation-wise decomposition. We overcome this by computing the Fréchet derivative, in total variation, via a Schrödinger linear-response theorem. 
Using Hadamard differentiability in the bounded-Lipschitz topology, we establish also asymptotic normality of the estimators, with dimension-free root-$n$ rate.
Numerical experiments  confirm the estimators' stability under data perturbation.
